### Root Cause

`google-protobuf` is listed implicitly via `grpcio-tools>=1.69.0` in `pyproject.toml` dependencies, but was never installed into the venv. The generated `.pb2.py` file was created on a different machine or environment where protobuf was available.

### Recommendation

This is NOT a blocker for G9. The cold-boot readiness test only requires raw TCP transport verification. Semantic protobuf validation is a separate concern for a later phase.
